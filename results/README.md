# Results

`latest.json` and `latest.md` are the output of the most recent benchmark run
committed to this repository. They contain aggregate metrics, per-sample
predictions keyed by opaque sample IDs and content hashes, the exact request
templates, and script hashes — but never email content, headers, credentials,
or a Cloudflare account ID.

Regenerate them with `npm run benchmark` (see the top-level README).
